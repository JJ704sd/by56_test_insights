## 2. 强制控制

- 仓库只保存模板、脱敏 fixture 和流程文档；真实输入、输出、重跑、差异和裁决保存到
  已批准的受控位置。`.gitignore` 已对 `pilots/` 和 `.r2-evidence/` 设置保护，但这
  不能替代存储权限和数据审批。
- 输入进入运行前必须完成 Secret/敏感数据扫描；扫描失败即停止，不把原始内容复制到普通
  日志、终端 transcript、Issue、PR 或聊天记录。
- 运行目录使用唯一 `run_id`/`change_id`；首次输入、首次输出、重跑和修正各用独立路径。
  任何重跑不得覆盖原文件；摘要只能引用原始证据。
- 影子 runner 只读隔离测试数据和代码引用，不持有生产凭据、部署 token、发布权限、写库
  权限或回滚权限。
- 共享报告只允许最小必要字段；Agent output、Prompt、知识库、用户数据和敏感 URL 不
  进入默认汇总，除非已有独立批准且完成脱敏。
- 到期删除必须可审计，删除记录包含范围、责任人、时间和存储系统回执；保留期内不得因
  重新运行而清理旧证据。

## 3. 事件处置

一旦发现 Secret、未脱敏数据、生产写入迹象或证据覆盖：

1. 立即停止影子运行和扩面，保留事件元数据但不要扩散敏感内容；
2. 通知 `TBD` 的安全接口人、项目负责人、测试负责人和发布负责人；
3. 按组织安全流程隔离、撤销/轮换凭据并记录处置证据；
4. 在责任人批准前不得恢复 8 周时钟，也不得把受影响样本计入主分母。
