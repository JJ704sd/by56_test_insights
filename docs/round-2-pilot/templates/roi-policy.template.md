## 计算口径

```text
月人工毛节省 = 基线人工分钟 - 影子流程人工分钟
月工具总成本 = 维护 + 误报复核 + flaky 调查 + runner/环境 + LLM/运行 + 数据维护
月净节省 = 月人工毛节省 - 月工具总成本
预计回本月数 = 一次性接入与建设分钟 / 月净节省
```

月净节省不为正时，回本周期为不可计算；不得用 `TBD`、未来频率或未经批准的估算把候选
写成 `CANDIDATE`。最终机器计算必须复用现有 `assess_automation_roi`，不得在模板或报告中
复制一套公式实现。

每个候选必须说明 `stable`、`repeatable`、Oracle 类型、运行频率、人工分钟、残余复核、
维护、flaky 调查、运行/LLM 等价成本、数据维护和一次性建设成本的来源。若任一成本或
观测窗口缺失，保留 `INSUFFICIENT_DATA`/`DO_NOT_AUTOMATE_YET`，不能用零补齐。

## 安全不可放宽

错误 `PASS`、确认的高风险漏选、未经授权自动放行和敏感数据事件均为 `0`；ROI 不能抵消
任何安全失败。
