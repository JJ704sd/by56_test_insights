## 建议完成顺序

依赖顺序为：`DEC-001` → `DEC-002` → `DEC-003` → `DEC-004` 与 `DEC-009` →
`DEC-005`、`DEC-006`、`DEC-007` → 形成真实目录/映射/人工基线 → `DEC-008` 与
`DEC-010` → 完成 `G0-011` 非阻塞演练 → `G0-012` 最终审计和签署。Wave B/C 的输入、
演练和审计不得在前置批准缺失时提前运行。

每项批准记录至少需要：`decision_id`、版本化来源、批准人及角色、时间戳、适用范围、
有效期、结论和受控证据引用。聊天口头结论、模板值、`TBD`、examples 和仓库测试结果
均不能替代批准记录。
